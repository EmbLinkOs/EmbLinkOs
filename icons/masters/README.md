# Icon masters — drop real art here

One PNG per icon, named after the icon. `make` turns each one into a
`system/images/<name>.eic` carrying every size the shell asks for:

    icons/masters/files.png     ->  /system/images/files.eic
    icons/masters/terminal.png  ->  /system/images/terminal.eic

Then point an app at it from its `user/bin/<name>.app` manifest:

    name Files
    icon /system/images/files.eic

## What makes a good master

- **RGBA PNG.** Transparency is resized correctly (premultiplied), so soft
  edges and shadows survive the reduction without halos.
- **Big.** 512×512 or 1024×1024. Every smaller size is generated by
  downscaling, which is what produces clean small icons — a 96px master
  cannot be sharpened back up into a good 128px icon, and the generator
  will warn you when a master is too small for the ladder.
- **Square.** A non-square image is padded onto a transparent canvas rather
  than stretched, so it will sit smaller than its neighbours.
- **Legible at 16px.** The same art is used for the smallest level; fine
  detail disappears there. Strong silhouette first, detail second.

Run `python3 tools/mkicons.py --list` to see which icons have real masters
and which are still falling back to the legacy 96×96 `.pam` art.
