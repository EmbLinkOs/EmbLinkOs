About Vellum

Vellum is the surface a document is written on. The name commits this to being a reader rather than implying a browser that will one day run web applications.

The pipeline

  1. fetch — bytes, from the filesystem now and over TCP and TLS next
  2. parse — HTML into a document tree, from bounded arenas
  3. style — a computed style per node, never mutating the tree
  4. layout and paint — EmUI, which already knows how to wrap text

The seam between styling and layout is the important one: layout reads only a computed style and never a tag name, so when CSS arrives the layout stage does not change at all.
