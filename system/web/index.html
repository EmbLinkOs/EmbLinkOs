Vellum

This page is being read by a browser this operating system wrote for itself. The bytes came off EMBKFS, the markup was parsed by user/web/html.c, the styling is a user-agent stylesheet in style.c, and every word you are looking at was rasterised from a TrueType outline by our own font engine.

What works

  • Headings, paragraphs and bold, italic and monospace runs
  • Lists, with text that hangs correctly under itself when it wraps rather than sliding back beneath the bullet
  • Links you can click — try the about page
  • Character references: & < > © — and ABC

Preformatted text

    struct vstyle {
        unsigned char display;
        unsigned char size, bold, italic, mono;
    };

Styling

The cascade is live: a page's own <style> block, its selectors and its inline style attributes all apply, in that order. See the styling demo.

Pictures

PNG decodes through our own DEFLATE and draws straight into the compositor's pixel format. See the picture demo.

Tables

Data tables render as a real grid, with aligned columns, header rows and column spans. See the table demo.

Scripting

A page's own JavaScript runs, and can read and change the document. See the scripting demo.

Interaction

Click handlers and timers reach a page's JavaScript. See the interactive demo.

fetch

A script can fetch data over the network. See the fetch demo.

What does not

No JavaScript and no CSS cascade yet. This is a document browser, and the design says so in docs/BROWSER.md rather than discovering it at milestone seven.
